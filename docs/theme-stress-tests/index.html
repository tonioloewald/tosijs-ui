Theme stress tests

<tosi-theme-editor> is not tied to tosijs-ui's own variables. Given a pattern, it finds the matching custom properties in the page's stylesheets, reads which variables each one is derived from, and offers the right control for each. These two themes are its stress tests: neither was written for it.

Each theme builds out from one colour, and every link of the chain can be overridden. Change the root colour and everything derived from it follows; override a link and what hangs from it follows the override instead.

Material's own token names (--md-sys-color-primary, --md-sys-shape-corner-*, --md-sys-elevation-level*, the type scale), with the containers and surfaces mixed from the primary colour.

test('the Material tokens are found, with their kinds and their chain', async () => {
  const editor = preview.querySelector('tosi-theme-editor')
  while (!editor.shadowRoot?.querySelector('[data-name="md-sys-color-primary"]')) {
    await new Promise((resolve) => requestAnimationFrame(resolve))
  }
  const field = (name) => editor.shadowRoot.querySelector(`[data-name="${name}"]`)
  expect(field('md-sys-color-primary').dataset.kind).toBe('color')
  expect(field('md-sys-shape-corner-large').dataset.kind).toBe('length')
  expect(field('md-sys-elevation-level1').dataset.kind).toBe('shadow')
  expect(field('md-sys-state-hover-opacity').dataset.kind).toBe('number')
  expect(field('md-ref-typeface-plain').dataset.kind).toBe('font-family')
  expect(field('md-sys-color-primary-container').querySelector('.chain').textContent).toBe(
    '← primary'
  )
})

Faux glass

The look of the react-tosijs and ngx-tosijs demos: translucent surfaces over a backdrop, blurred and saturated, with a light rim and pill-shaped controls. The surfaces are the tint at an opacity, so a translucent colour must survive editing.

It also declares modes of its own beyond light and dark: tinted (every colour toward the accent's hue) and monochrome. Each is derived from the few root colours; the surfaces, rim and field follow in the browser because they are mixed from the tint.

test('a declared mode derives the roots, and the mixes follow', async () => {
  const editor = preview.querySelector('tosi-theme-editor')
  while (!editor.shadowRoot?.querySelector('[data-mode="mono"]')) {
    await new Promise((resolve) => requestAnimationFrame(resolve))
  }
  const demo = preview.querySelector('.glass-demo')
  const variable = (name) => getComputedStyle(demo).getPropertyValue(`--${name}`).trim()
  const frame = () => new Promise((resolve) => requestAnimationFrame(resolve))
  const pick = async (mode) => {
    editor.shadowRoot.querySelector(`[data-mode="${mode}"]`).click()
    while (!document.body.classList.contains(`glass-${mode}`) && mode !== 'light') await frame()
    await frame()
  }
  expect(variable('glass-accent')).toBe('#3355dd')
  await pick('mono')
  const grey = variable('glass-accent').slice(1)
  expect(grey.slice(0, 2) === grey.slice(2, 4) && grey.slice(2, 4) === grey.slice(4, 6)).toBe(true)
  expect(variable('glass-backdrop')).not.toContain('#6087ba')
  // Not rewritten: the browser mixes it from the (monochrome) tint, as in every mode.
  expect(variable('glass-surface')).toContain(`${variable('glass-tint')} 20%`)
  await pick('light')
  expect(document.body.classList.contains('glass-mono')).toBe(false)
  expect(variable('glass-accent')).toBe('#3355dd')
})
