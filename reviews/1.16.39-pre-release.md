# 1.16.39 pre-release review

**Verdict: GO** (historical once tagged). Patch: the doc-site frame passes the WCAG 2.2 AA rules an
adopter's axe scan failed (#3520), `devServer()` builds on start (#3524), tables have a margin
(#3553). All three were filed by downstream projects (*Learn 3D with Cheetah 3D*, foresight-rpg).
Tier 0 plus correctness and blast radius at fast depth, each lens given the code, not the author's
conclusions.

## Is it a patch?

The one change an adopter can feel is the nav markup: `<details><summary><a>` became a toggle
button beside the link, so site CSS targeting `.doc-nav details`/`summary` stops matching. The old
markup was never documented (the blast-radius lens grepped the docs, `src/docs` and `llms.txt`),
and it was itself the accessibility failure: the 1.16.15 / 1.16.19 ground, breakage that only
rejects what was already wrong. The CHANGELOG names the new classes. `initialBuild` is a new
default with an opt-out that changes no output (the 1.16.2 test). Both lenses called patch
defensible; the maintainer had agreed the larger accessibility work (#3521, #3522) is the minor.
