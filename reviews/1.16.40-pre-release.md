# 1.16.40 pre-release review

**Verdict: GO** (historical once tagged). Patch:
- an example with no script constructs no function, so HTML examples and `run` dialects work under a CSP without `'unsafe-eval'` (GitHub tosijs-ui#245 addendum, #246 points 1–2, from Snowfox);
- the doc header's search hint is "Search", settable with `searchPlaceholder` and localized;
- the trigger's ⌘K hint has no outline.

The rest of #245 and #246 (a CSP-compatible path for script examples, a no-code example mode) is planned for 1.17.0, as the maintainer agreed. Tier 0 plus one combined correctness and blast-radius lens, given the code.

## Is it a patch?

- **The CSP fix** removes a failure; nothing that ran before stops running.
- **The default hint changes text and accessible name** on every doc site: "Search documentation" becomes "Search". The maintainer asked for it. It is cosmetic, and one config line restores it, which the CHANGELOG says. Flagged to the maintainer, because no past ruling covers reader-facing text.
- **The ⌘K outline** is a `[change]` that `release-check` flags. It is cosmetic, the maintainer asked for it, and the notes say what moved.
