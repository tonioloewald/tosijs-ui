## Findings

### Minor
- **(unverified; confirmed by reading the code) The public router still pushes duplicate same-URL entries.** In `src/router.ts:333`, `navigate()` calls `window.history.pushState({}, '', '/' + path)` with no same-URL check. An adopter whose nav link points at the current route gets the exact symptom #174 reported: Back appears to do nothing. The fix only reached doc-site readers. The doc-browser popstate "keep editing" push (`doc-browser.ts:895`) is correct as it stands, because the URL has already moved there.

### Nit
- **(unverified; confirmed by reading the code) The same-page check ignores the current hash.** Suppose the reader is on `/carousel/#some-example` and clicks the "Carousel" nav entry (`/carousel/`). The code now calls `replaceState`, and the anchored entry is lost as a Back target. Before this change it was pushed. A native link from `/carousel/#x` to `/carousel/` is a different URL and pushes. So the comment and the CHANGELOG ("as a native same-URL navigation does") overstate the match.

## Follow-ups by destination

### This repo: the virta board (CLAUDE.md says tasks live there now, not `TODO.md`)
- [ ] **router.ts `navigate()` same-URL replace (#174 sibling).** Compare the target pathname+search to `location` and use `replaceState` when they match. Better still, factor a shared `pushOrReplace(href)` used by both `router.ts` and `doc-browser.ts` `go()`, so the policy has one home. This is an additive fix, so it can ship as a patch.
- [ ] **Hash handling in `go()`.** Either treat it as "same" only when `location.hash === ''` (or compare full resolved hrefs), or narrow the code comment and the CHANGELOG wording to "same path and query". Add a Playwright case: start at `/carousel/#x`, click `/carousel/`, and expect `history.length` to go up by 1.
- [ ] **Same-page identity mismatch.** `go()` compares raw `pathname`/`search`, but the popstate guard and `filenameFromLocation()` compare the resolved filename (`slugForPath`). On hosts that serve `/carousel` without the trailing slash, or `/carousel/index.html`, `same` is false and the duplicate push comes back. Consider `filename === filenameFromLocation()`.
- [ ] **Query-routing coverage.** `routing: 'query'` (the default) is untested for #174. Extra params such as `?file&_testMode=1` never count as "same", so it quietly falls back to push. The test-failure menu (~L2048) also routes through `go()` to the current page. Add a test.
- [ ] **Hashed content links.** A same-page link like `/carousel/#example-2` goes through `docFilenameForHref` → `go()` and loses the fragment. That predates this change, but replace now also destroys the origin entry. Track it with the hash item above.
