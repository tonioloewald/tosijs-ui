## Accepted, not fixed

- **Read-only checkout or unwritable project root:** a redeemed link gets its session and no pass, with the warning (was a 500 and a spent link; now degraded, not broken).
- **Shared machine, someone else's `.tosijs-dev/`:** passes off with a warning.
- **Secret owner and folder mode not checked; symlinked output folder not resolved; race between `wx` create and write with two servers on one project:** each needs write access to the project already, or two servers on one tree.
- **`table.columns.push()` on an empty table mutates the shared sentinel:** before, the push was silently lost; nobody is worse off.
- **`AuthState.links` is now a `ReadonlyMap`:** internal module, not re-exported from `tosijs-ui/site`; reachable only through the deep-import wildcard.
- **No unit test that `devServer` sets the cookie on redemption:** the e2e in `tests/global-keys.pw.ts` drives it end to end.
