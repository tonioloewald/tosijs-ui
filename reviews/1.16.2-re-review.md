## Findings by severity

### Minor

1. **(unverified) A cycle that passes through a Map or Set makes `formatConsoleValue` print `[object Object]` or `[object Map]`.** File: `src/live-example/example-console.ts:80`, lens: correctness.
   - **Cause:** the replacer returns a fresh `{Map: …}` or `{Set: …}` wrapper. `JSON.stringify` then calls the replacer with that wrapper as `this`, so the loop that trims the path to the current holder pops every entry and discards the ancestry.
   - **Result:** a cycle through the Map is never detected, `JSON.stringify` throws, and the code falls back to `String(value)`.
   - **Regression:** a parent pointer stored inside a Map now prints worse than it did before the remediation, which printed `children: {}`.
   - **Fix:** push the wrapper onto `path` before returning it. Add tests for a Map that contains itself and for a parent pointer inside a Map value.
2. **(unverified) `declaresConsole` is a regex that knows nothing about scope or syntax.** File: `src/live-example/example-console.ts:138`, lens: correctness.
   - **False positives:** a nested `function f(){ const console = 1 }`, a commented-out `// let console`, and `const console$`. In each case the example silently loses its console panel.
   - **False negatives:** `let a = 1, console = 2` and `const { console } = globalThis`. These still throw "Identifier 'console' has already been declared", the exact failure the fix was meant to prevent.
   - **Scope:** `executeInline` and `executeInIframe` share the predicate, so both paths are affected.
   - **Fix:** decide from the compile result instead of the regex. Try to build the function with `console` as a parameter. If that throws a SyntaxError that names `console`, rebuild without the parameter. Add tests for both directions.
3. **(unverified) Nothing checks that `buildSite` stamps `__TOSI_EXAMPLE_CONSOLE=false` into the page head.** File: `src/doc-system/site/orchestrator.ts:1450`, lens: correctness, gate 2.
   - **Gap:** the only test sets the global by hand. If `consoleHead` were dropped from `headExtra`, the global renamed on one side, or the stamp emitted after the bundle script, `exampleConsole: false` would do nothing and every test would stay green. That option is the headline `[new]` of this release.
   - **Fix:** add a `buildSite` test, next to the `__TOSI_EXAMPLE_POLICY` / opt-in test, that checks two things:
     - the stamp is present, and comes before the bundle script, when `exampleConsole: false` is set;
     - the stamp is absent by default.

### Nit

4. **(unverified) `src/reduced-motion.ts` says it is "internal", but the `./*` and `./*.js` wildcards publish it as `tosijs-ui/reduced-motion`.** That includes `resetReducedMotionForTests`. File: `src/reduced-motion.ts:4`, lens: blast-radius.
   - **Fix:** mark both exports `@internal` in JSDoc, or reword the comment to say the module is not in the root barrel but can be reached by subpath.
