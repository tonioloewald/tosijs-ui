## Fix before the tag (verified majors)

- [ ] **`<tosi-palette>` `shortcut` silently drops unknown modifiers, so `'cmd+k'` binds the bare `k` key page-wide and swallows it.** (docs lens, verified) `src/palette.ts:169`. `matchesShortcut` puts `cmd`, `command` or `option` in `want` but never checks them, and it requires every known modifier to be false. Result: `matchesShortcut({key:'k'}, 'cmd+k') === true`, and the listener at `:555` calls `preventDefault()` on every plain `k`, including in text inputs.
  - **Fix:** reject unknown modifier words. Treat the shortcut as unset and `console.warn` once, naming `mod/meta/ctrl/shift/alt`. List that vocabulary in the Properties docs. In the same function, also guard `event.key` (see the verified minor below): `const key = event.key?.toLowerCase(); if (!key || key !== wanted) return false`.
  - **Check that clears it:** a unit test where `matchesShortcut(new KeyboardEvent('keydown',{key:'k'}), 'cmd+k')` is `false` and a warning was emitted, plus `matchesShortcut(new Event('keydown'), 'mod+k')` returns `false` without throwing. Both must fail with the fix reverted.
