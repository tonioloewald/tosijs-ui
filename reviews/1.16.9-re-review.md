## Major (confirmed, not blocking)

### F1. A file entry in `docPaths` makes its whole parent directory a fragment root (correctness and blast-radius, both confirmed)

- **Where:** `/Users/tonioloewald/tosijs-ui/src/doc-system/site/docs.ts:647-653` maps each doc path to `isDirectory() ? p : path.dirname(p)`.
- **Effect:** with `README.md` listed, the project root is a root. That is the default (`['src', 'README.md']`) and this repo's own config.
- **Reproduced:** with `paths: ['docs', 'README.md']`, `docs/page.md` insetting `../notes/_x.md` builds green with the text in the page. With `paths: ['docs']` the same inset throws "outside the doc paths".
- **Promise contradicted:** `src/doc-system/doc-site-system.md:1235` ("must sit under one of your `docPaths`"), `CHANGELOG.md:26-27` ("under your doc paths"), and the comment at `docs.ts:646`.
- **Bounds:** only `_`-prefixed `.md`/`.markdown`; dot directories and `node_modules`, `dist`, `build`, `reviews` are still refused; the actor needs edit access to a page (source editor or tunnel).
- **Fix:** a file entry contributes no root, or only that exact file. Add a test with `paths: [docsDir, readmeFile]` asserting `../notes/_x.md` is refused. This is a few lines; do it before the tag.
- **Re-review scope if fixed:** correctness and security over that diff only.

### F2. The fragment gate honours ignores by basename only (correctness rated it minor, blast-radius major; both confirmed, kept at major)

- **Where:** `/Users/tonioloewald/tosijs-ui/src/doc-system/site/single-source.ts:253-254` tests `ignore.has(segment)`. Extraction's `traverseDirectory` (`docs.ts:462-465`) matches by basename or by resolved path.
- **Reproduced:** `extractDocs({ paths: ['src'], ignore: ['src/private'] })` drops `src/private/p.md` from the corpus but publishes `src/private/_x.md` when a page insets it. The basename form `ignore: ['private']` throws as intended.
- **Promise contradicted:** `doc-site-system.md:1235` ("outside any ignored or dot-prefixed directory"). `site-config.ts:77-81` documents `ignoreDocPaths` as accepting both forms.
- **Structural point:** this is a second copy of the ignore rule, the same failure class this repo records for `isLiveFence`.
- **Fix:** extract one predicate (for example `isIgnoredDir(dir, ignore, isRoot)`) from `traverseDirectory` and call it for each ancestor between the root and the fragment. Add a path-form case to the real-directory tests.
- **Bounds:** needs a path-form ignore and a deliberate inset by a page editor.
