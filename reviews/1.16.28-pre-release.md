## Fix before the tag

- [ ] **M1 (major, verified by blast-radius, security and docs): `tosijs-tunnel` prints the permanent, machine-wide global edit key on every start, under the heading "Pass on".**
  - **Where:** `bin/tunnel.ts:129` (`shareLinksFor`), `bin/tunnel.ts:480-486` (output), and `src/doc-system/site/dev-auth.ts` `globalKeyLinks`, which builds `?t=<raw key>`.
  - **What changed:** in v1.16.27 the tunnel printed no key at all. The only credential it printed was the short-lived `--link` code, and only on request. Now every plain start prints `edit: https://<domain>/?t=<PREVIEW_EDIT_TOKEN>&to=…`.
  - **Why it matters:** that line ends up in scrollback, agent transcripts that sync off the machine, screen shares, and the box's Caddy access log. The key gives write access to every workspace that accepts it and never expires. Revoking it means rotating the key by hand on the box and on every machine.
  - **The wording makes it worse:** the tunnel heading ("Pass on"), the `globalKeyLinks` docstring ("passed to a person or another device") and the CHANGELOG all invite handing it to people, while `--link --share` already makes expiring, single-workspace links for that.
  - **The only way to stop the print** is `globalKeys: false` or `'view'`, and both also turn the feature off.
  - **Fix:**
    - Print the view link by default if you like.
    - Print the edit link only on an explicit request (for example `--link --global` or `--keys`), or mask it by default (`?t=<edit key from ~/local-secrets>`).
    - Reword the tunnel output, the `globalKeyLinks` docstring, the `doc-site-system.md` "Global keys" paragraph and the 1.16.28 CHANGELOG bullet. The edit link is for your own devices only, and people get `--link --share`.
  - **Check that clears it:** a unit test on the tunnel's output text (or an extracted formatter) asserting that a default start with PREVIEW_EDIT_TOKEN set does not contain the raw edit key, and that the opt-in flag does. The test must fail with the fix reverted. Also grep the doc and CHANGELOG for the old "pass on" / "passed to a person" wording and confirm it is gone.
