## Delta since the last report
Commit `2901da3a9` changes four files: `src/icons.ts`, `src/icons.test.ts`, `CHANGELOG.md` and `demo/docs.json`.
- **Cycle detection.** `resolveIcon` now catches a redirect cycle when it revisits a name, using a `seen` set. `MAX_REDIRECTS = 10` is removed, not kept beside the new check. A long chain that is not a cycle now resolves.
- **`data-icon` naming.** When a redirect resolves to a composite, `data-icon` now holds the alias name instead of the composition string. Only redirect-to-stack names are affected, and those drew a square in the published 1.16.17, so adopters had no working behaviour to depend on.
- **Stricter tests.** The known-icons test now asserts that every listed name exists; it used to require only a count above 50. The doc-example test now asserts the outer composites by `data-icon`.
