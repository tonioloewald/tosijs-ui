# 1.16.37 pre-release review

**Verdict: GO** (historical once tagged). Patch: the doc-site test runner works in Safari and runs
over the tunnel; the header's pass badge greys by filter. Tier 0 plus correctness and blast radius
at fast depth, each lens given the code, not the author's conclusions.

## Is it a patch?

`release-check` flagged the `[change]` bullet (pages the dev server serves start with tests on).
It lands only on people looking at a site through its dev server, never on a deployed site or an
adopter's product: the same ground as the 1.16.31 ruling. The maintainer asked for it ("I do want
tests to run on the tunnel").
