## Fix before tagging (verified regressions in this diff)

**1. Major, severity uncertain (verified, correctness): `liveFenceLanguages` finds no fences in a CRLF corpus.**
- **Where:** `/Users/tonioloewald/tosijs-ui/src/doc-system/site/build-warnings.ts:57-58`.
- **What:** lines come from `split('\n')` and keep their trailing `\r`; the fence regex has no `m` flag, so `.` and `$` fail on every fence line. Measured: a CRLF `js` fence returns `[]`; the same text with LF returns `['js']`.
- **Why it is a regression:** both regexes this commit replaced (the old bundle-guard regex and the old llms.txt regex) matched the same CRLF text. The hole already existed for the tjs-lang check; the commit extended it to two more callers.
- **Effect:** on a corpus where every doc with a live fence is CRLF, `docsHaveExamples` is false, a `strict: true` build passes with a bundle that never registers `<tosi-example>`, and llms.txt drops its live-example note. Built pages are unaffected.
- **Reach:** needs `core.autocrlf=true` (the Git for Windows default) or CRLF-committed files in the adopter's tree. `docs.ts` does not normalise line endings. Whether `buildSite` otherwise runs end to end on Windows was not checked.
- **Why not a blocker:** narrow population, and the loss is a diagnostic rather than broken output. The verifier noted a case for minor. It is still a fail-open of the gate this release introduces.
- **Fix:** split on `/\r?\n/` and add a CRLF case to `build-warnings.test.ts`.

**2. Minor, severity uncertain (verified, correctness): the missing-module message never reaches the Console REPL, contradicting the CHANGELOG.**
- **Where:** `/Users/tonioloewald/tosijs-ui/src/live-example/component.ts:1302` (`consoleEval`) and `:1534` (`evalInExample`); the keydown handler at `:1246` voids the promise.
- **What:** `rewriteContextImports` now throws, and both calls sit before the `try` whose catch writes the error line. The reader sees their input echoed and nothing else; the browser logs an unhandled rejection.
- **Why it is a regression:** before this commit the same input produced a visible, if cryptic, `TypeError` line.
- **CHANGELOG:** line 45 says the message appears "whether it is met in the example, its tests or the Console tab's REPL". The REPL is the one path where that is false.
- **Fix:** move both calls inside their existing `try` blocks and add a `consoleEval` test with an undefined context module. If this is deferred instead, the CHANGELOG sentence must be corrected before the tag.
- Confirmed by reading the control flow; no browser repro was run.
