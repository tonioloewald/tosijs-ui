# Documentation System

<!--{ "pin": "bottom", "order": 4, "description": "tosijs-ui/site: turn markdown and doc comments into a static, pre-rendered documentation site with live, self-testing examples, an ePub and print." }-->

The site you are reading is built by `tosijs-ui/site`, and your project can use it too. It
turns markdown and `/*#` doc comments into a static, pre-rendered site whose code examples
run live and test themselves, plus an ePub, print, `llms.txt` and a sitemap.

Start with [Adopting the doc system](/adopting-the-doc-system/) for a first build, then
[Doc-Site System](/doc-site-system/) for every option.
